## 🚀 Quick Start

### Prerequisites
- Python 3.8+
- Node.js 20+
- Groq API Key (free at console.groq.com)

### Setup

1. **Backend:**
bash
cd backend
pip install -r requirements.txt
echo "GROQ_API_KEY=your_key_here" > .env
python api_server.py


2. **Frontend:**
bash
npm install
npm run dev


3. **Open:** http://localhost:3000
